# Бот записи ТехноМоторики

Telegram-бот и мини-приложение онлайн-записи. Работает на Cloudflare Workers, хранит данные в Cloudflare D1. Бесплатный тариф Cloudflare разрешает коммерческое использование.

## Как он работает

**Клиент** записывается в мини-приложении (кнопка «Запись» слева от поля ввода в чате с ботом) или прямо в чате. Мини-приложение сделано в стиле сайта: `public/app/index.html`. Клиент выбирает услугу, день и время, оставляет номер и марку авто. Время сразу закрепляется за ним, накануне в 12:00 приходит напоминание. Запись можно отменить в «Мои записи».

**Владелец:** получает каждую новую запись и каждую отмену с телефоном и авто клиента.
- `/day` — расписание по дням, отмена записей.
- `/close` — закрыть время (обед, личный клиент, выходной).
- В 09:00 приходит расписание на день.

**Почему два человека не могут занять одно время.** День разбит на ячейки по 30 минут. Таблица `cells` имеет `PRIMARY KEY (day, cell)`. Запись и все её ячейки вставляются одной транзакцией. Если хоть одна ячейка уже занята, база отклоняет вставку целиком, и бот предлагает выбрать другое время. Это проверено тестом: 20 одновременных попыток на один слот, записывается ровно одна.

**Мини-приложение** берёт пользователя из подписанного `initData` Telegram (HMAC от токена бота), подделать чужой Telegram ID нельзя. API: `/api/init`, `/api/days`, `/api/slots`, `/api/book`, `/api/cancel`.

## Установка (один раз, около 5 минут)

Нужен Node.js 18+ и аккаунт Cloudflare (бесплатный).

1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → скопируйте токен.
2. В терминале:
   ```bash
   cd bot
   npm install
   npm run setup
   ```
   Скрипт попросит токен, откроет браузер для входа в Cloudflare и сам создаст базу и таблицы, задеплоит бота, сохранит секреты и подключит Telegram. В конце выведет ссылку на бота и **код владельца**.
3. Владелец пишет боту `/admin КОД`. Всё, записи пойдут ему.

Если на шаге деплоя Cloudflare попросит выбрать поддомен `workers.dev`, придумайте любой. Если что-то пошло не так, скрипт можно запускать повторно.

## Настройка

Всё в `src/config.js`: часы работы, выходные, на сколько дней вперёд можно записаться, услуги с ценами и длительностью (`len: 2` — это 1 час). После правок выполните `npm run deploy`.

```bash
# в .dev.vars: BOT_TOKEN=test, WEBHOOK_SECRET=test_secret, ADMIN_CODE=test_code, TG_API=http://127.0.0.1:9999
npx wrangler dev --port 8787 &

node test/api.mjs # мини-приложение (на чистой базе)
```
